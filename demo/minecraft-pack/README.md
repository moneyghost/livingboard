# Demo: a Minecraft mod from the board

`frost_golem_BP/` and `frost_golem_RP/` were generated by the agent reading the example board
(Frost Golem, Frost Shard, Ice Spikes, a hand-drawn sword, a recipe edited from the interactive view).

To redo it from scratch with Claude Code:

1. Start Livingboard from the repo root: `pnpm dev`, then open http://localhost:5180.
2. Open Claude Code in this folder: the `.mcp.json` file already registers the `livingboard` server.
3. In Claude Code: `/mcp__livingboard__start`.
4. Draw. The agent's instructions are in `CLAUDE.md`.
